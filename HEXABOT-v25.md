# HexaBot v25 · Interactive Desktop Companion

HexaBot now behaves like a living desktop companion inspired by the interaction model of classic assistants, while keeping an original HexaSec visual identity.

- Full character floating above the chat launcher.
- Natural idle movement, antenna pulse, orbital effects and blinking.
- Eyes follow the pointer on desktop.
- Greeting bubble and spontaneous idle reactions.
- Context states: greeting, attentive, thinking, speaking, success and error.
- Thinking particles, scan effect, body motion and wave gesture.
- Character opens/focuses the chat when clicked.
- Desktop character relocates beside the open panel; mobile hides it while the panel is open.
- Reduced-motion accessibility support.
- No external animation library or GIF required.
